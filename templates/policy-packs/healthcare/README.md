# Healthcare policy pack (template)

`policy-pack.json` in this folder is a **starter** vertical pack: it lists compliance rule **keys** and advisory defaults you can promote into a versioned policy pack through the architect workspace or API.

- Do not treat this file as a legal HIPAA attestation — it is an architecture-governance starting point.
- Pair with [`docs/library/walkthroughs/POLICY_PACK_HEALTHCARE_CLAIMS_PILOT.md`](../../../docs/library/walkthroughs/POLICY_PACK_HEALTHCARE_CLAIMS_PILOT.md#healthcare-vertical-positioning-sales--architecture) (`buyer-jobs/HEALTHCARE_CLAIMS_POLICY_REVIEW.md` alias) and [`docs/go-to-market/trust-center.md`](../../../docs/go-to-market/trust-center.md) for buyer-facing boundaries (no PHI in briefs).
