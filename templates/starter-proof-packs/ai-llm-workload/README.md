# AI / LLM workload (starter)

## When to use

- Prospect runs a **copilot, RAG, or agentic** workload on Azure (e.g. Azure OpenAI, APIM gateway, vector search) and wants a **second** architecture review focused on **governance, segmentation, and observability** — without real prompts or production model behavior claims.

## What is in this pack

| File | Purpose |
|------|---------|
| `second-run.json` | SECOND_RUN for CLI or wizard paste |
| `architecture-request.json` | Full `POST /v1/architecture/request` body |
| `policy-context.json` | Points at `templates/policy-packs/ai-llm` |
| `proof-package-checklist.md` | Checklist for the committed review package |

## What not to claim

- Do **not** claim **model safety**, **bias elimination**, or **responsible-AI program maturity** from ArchLucid outputs.
- Do **not** present **accuracy**, **hallucination rate**, or **benchmark scores** unless you attach your own measured evidence outside this starter.
- Do **not** paste **real** customer prompts, **IP**, or **regulated** corpus excerpts into demos.
