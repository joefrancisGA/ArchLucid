## When to use

- Prospect runs **multi-tenant B2B SaaS** on Azure and procurement asks about **SOC 2–style** logical access, change management, and subprocessors.
- You want a **second** review quickly with constraints that resemble a vendor diligence questionnaire, **without** real customer data.
