# Azure cost and governance review (starter)

## When to use

- Prospect wants a **second** pass focused on **FinOps** framing (showback, budgets, anomaly questions) plus **Azure Policy / landing zone** guardrails — still at **architecture review** depth, not a billing audit.

## What is in this pack

| File | Purpose |
|------|---------|
| `second-run.json` | SECOND_RUN for CLI or wizard paste |
| `architecture-request.json` | Full POST body |
| `policy-context.json` | Points at `templates/policy-packs/financial-services` for control-style governance vocabulary |
| `proof-package-checklist.md` | Checklist for the committed package |

## What not to claim

- Do **not** invent **dollar savings**, **percentage waste**, or **optimized bill** outcomes.
- Do **not** present the review as a substitute for **Azure Cost Management**, **FinOps dashboards**, or **internal chargeback** systems.
- Do **not** attribute **policy compliance** of a live tenant to this exercise.

## Sample disclaimer

Numbers, SKUs, and subscription names are **placeholders**. Cost and policy **posture** must be validated against your real Azure estate and management-group design.
