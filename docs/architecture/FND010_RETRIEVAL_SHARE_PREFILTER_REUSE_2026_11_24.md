## Findings and implementation
HTTP run-only search performed a seal check but no share authorization; manifest-only search did neither ownership resolution nor sharing; project-wide search could rank chunks belonging to restricted architecture runs. The public hit model has no run ID, and the service can rerank, summarize or critique hit text before returning it. Existing GlobalSearchShareAccessFilter targets a different DTO and filters after a search, unsuitable for this data flow. Reuse its underlying canonical share gate, not a new ACL.

Explicit run: use existing share gate before seal/read. Manifest: resolve scoped run metadata, reject empty/mismatched/denied ownership with generic manifest 404, recheck summary linkage and use shared exact-manifest seal guard for current/historical documents. Both facets intersect at index query. Project: enumerate existing scoped keyset run list, authorize each unique nonempty ID through canonical gate, return empty if no visible run, and reject incomplete enumeration with 409 instead of falling back to unrestricted search. At most five pages of 100; archived/unlisted and unproven runs are excluded. This is a deliberately bounded initial implementation, not a scalable project-wide entitlement index. Gate/list consistency and TOCTOU remain bounded by existing repository/cache behavior, not transactional revocation.

Extend existing RetrievalQuery with optional server-owned AuthorizedEvidenceRunIds. Null retains existing internal behavior; empty denies tenant evidence. Both vector backends intersect tenant/workspace/project, run/manifest facets and permitted run IDs before ranking. Azure SDK sets PreFilter explicitly. Only reviewed single-run evidence corpora (TenantManifest, PriorManifest, KnowledgeGraphNode) are permitted under the new restriction. Conversation chunks can encode comparison evidence under one run ID and therefore cannot be trusted by that tag alone. Runless/other unproven corpus kinds excluded. Platform corpora retain independent existing rules for internal callers; HTTP does not opt in. Candidate and retry clones carry the set. Disable Graph-RAG neighbor expansion under an authorized evidence restriction pending separate snapshot ownership proof. Indexed graph seed chunks remain eligible. No index schema change, new control package or infrastructure provisioning.
