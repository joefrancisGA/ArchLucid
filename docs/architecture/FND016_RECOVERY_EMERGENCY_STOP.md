# FND-016 independently verified recovery and durable emergency stop

Migration 356 introduces a tenant/project-scoped emergency-stop table with monotonically increasing generation and a generation-checked mutation procedure. A missing record is a **stop condition**. Only an independently privileged control-plane identity should receive EXECUTE on SetRemediationEmergencyStop; execution workers should receive read-only access. Database failure, absent records, unverified authority, stale snapshots, or active stop must deny.

The pure recovery gate requires the FND-016 preliminary review, fresh independently verified stop snapshot, and a fresh independently signed recovery rehearsal attestation bound to tenant/project/proposal and source/rollback digests. Even if all checks pass it returns `review_required` and never grants execution.

**Implemented as non-executing Python references:** parameterized stop-state reader (`fnd016_trusted_stop_reader.py`), signed Ed25519 recovery attestation verifier (`fnd016_signed_recovery_attestation.py`), evidence-bound v2 verifier (`fnd016_evidence_bound_attestation.py`), and isolated in-memory rehearsal (`fnd016_isolated_recovery_rehearsal.py`). These functions are not demonstrated to be registered in any production runtime.

**Not yet implemented as production enforcement:** SQL stop-state reader/writer adapters, trusted production attestation verification and signing key custody, durable independent stop-control authority, real cloud rehearsal runner, immediate cancellation of in-flight operations, production executor wiring, or live SQL integration verification. A caller-provided `authority_verified` flag remains an adapter contract, not cryptographic proof; the reference recovery gate now requires the literal Boolean `True` for independently verified authority, signature, and rehearsal claims, and literal `False` for a cleared stop. The stop generation must be re-read and compared atomically immediately before any future execution. SQL migration must be deployed separately with least-privilege grants. No production remediation enabled.
