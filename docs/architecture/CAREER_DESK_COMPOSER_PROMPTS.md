## The problem these prompts solve

Casual tools optimize first-run success, sample recovery, wizard collapse, wait-on-this-tab, confirm-then-forever, and a package that looks done.

Livelihood tools optimize resume, keyboard work, in-flight queue, amendable writes, honest coverage, a cited “no,” a trail at the stamp, and a meeting that survives token refresh.

Production UX now has Working overlays and WA gates. The remaining failures are: first-week copy that still describes a locked sidebar, empty presets that still hero samples, ADR 0067 tests that force two start products onto Working, eval chrome on print/inspect, “decision-grade” screenshots that bury typed-engine-protected, print/PDF/export trails, Guided dual maps, duplicate report pages, remaining amend mounts, Overview last-open package, and first-week chrome still on the open review.
