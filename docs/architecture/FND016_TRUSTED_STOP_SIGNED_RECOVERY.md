# FND-016 trusted stop reader and signed recovery evidence

This increment adds a parameterized read-only stop-state adapter and a canonical Ed25519 recovery attestation verifier. The stop reader returns an active, unverified stop when the SQL row is missing, malformed, or unavailable. The attestation verifier requires an independently pinned public key, exact signing key ID, signed tenant/project/proposal/source/rollback bindings, a timezone-aware timestamp, and a successful rehearsal flag. These adapters feed the existing FND-016 recovery gate.

**Trust and deployment limitations:** The SQL adapter accepts an injected query callback; production must supply an authenticated read-only SQL client, enforce parameter binding and source freshness, and prevent forged results. A pinned key and a valid signature prove who attested, **not that the rehearsal actually happened**; independent recovery-service provenance and immutable evidence storage remain required. The execution gate must independently re-read stop generation immediately before acting. This PR does not implement production SQL connectivity, actual recovery rehearsal, key provisioning, in-flight cancellation, or remediation execution.
