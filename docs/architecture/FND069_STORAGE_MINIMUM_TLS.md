# FND-069 Azure Storage minimum TLS verification

This slice independently verifies one exact claim: the configured minimum TLS
version for a specific Azure Storage account is 1.2. It does not test live TLS
handshakes, policy enforcement, network reachability, or any other resource type.

ArchLucid resolves the current run share and authorized inventory binding, uses the
deterministic observation in the existing publication gate, and repeats the scoped
check before persistence. A cached review cannot publish. Missing or contradictory
observations cannot be replaced by semantic model agreement. SecureNow requires a
cited inventory hop from the scoped path and substitutes a deterministic explanation
for model text making the covered claim. A verified configuration setting includes
the snapshot, resource row, capture time and verifier version. Other path inferences
are not established by this fact.

Only one matching in-scope Storage row and one recognized, non-redacted property in
a successful inventory capture no older than 24 hours can support the claim.
Unrecognized, stale, missing or ambiguous evidence is unverified. A known version
other than 1.2 contradicts the exact claim. This slice does not change provider
quarantine signals or certify any other decision-grade claims. FND-069 remains partial.
