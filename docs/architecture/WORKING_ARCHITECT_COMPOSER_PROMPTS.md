## The problem these prompts solve

Casual tools optimize first-run success, sample recovery, wizard collapse, wait-on-this-tab, confirm-then-forever, and a package that looks done.

Livelihood tools optimize resume, keyboard work, in-flight queue, amendable writes, honest coverage, a cited “no,” a trail at the stamp, and a meeting that survives token refresh.

Production UX now has Working overlays and RS/LD gates. The remaining failures are: eval chrome still branching on buyer-polish at call sites, nav/help that still teach two products, Ask/sponsor/Compare that can overclaim, no legal new-version after spawn lock, seal-reason copy drift, receipts in the appendix, prefs/restore/keepalive gaps, and meeting/search/what-if leftovers.
