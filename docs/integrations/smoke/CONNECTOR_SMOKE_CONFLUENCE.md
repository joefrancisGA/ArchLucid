# Smoke — Confluence Cloud (first-party publish)

## Purpose

Verify **one-way publish** of the canonical first-value **Markdown** for a run into a configured space ([V1_SCOPE.md](../../library/V1_SCOPE.md) §2.15). The publisher sends **Authority-shaped** Markdown from the in-product report builder to the connector — there is no duplicate “Confluence document schema” stored in ArchLucid beyond **`RunId`** and link base for URLs.

## Prerequisites

- **Confluence Cloud** space for pilot content (`Confluence:DefaultSpaceKey` or tenant-equivalent configuration).
- API token + user (basic auth to Cloud) per [INTEGRATION_CATALOG.md](../../go-to-market/INTEGRATION_CATALOG.md); secrets in **Key Vault**, not operator docs.
- A **committed** run id suitable for smoke (non-prod space).
- **Admin** API caller for the publish endpoint in hosted deployments (`AdminAuthority` policy).

## Auth and secret pattern

- **Confluence REST:** Username + API token (Basic) for V1 MVP; OAuth follow-on per scope doc.
- Host configuration references secret **names** for token retrieval — do not embed tokens in tickets or markdown.

## Test payload (Authority-shaped)

**Admin publish** — stable contract in OpenAPI; body shape:

```json
{
  "runId": "<run id string (GUID or canonical run id per API)>",
  "apiBaseForLinks": "https://your-api-host.example"
}
```

`apiBaseForLinks` may be omitted to default from the request host. The publisher loads the run, resolves scope, builds **Markdown** via the first-value report builder, and passes that Markdown as the connector payload (verbatim body text for the page — not a hand-written Confluence storage XML schema in ArchLucid).

## Expected ArchLucid audit events

| Outcome | Event type |
|---------|-------------|
| Page created and id returned | `Integration.ConfluenceFirstValueReportPublished` — JSON includes `runId` and `externalPageId` (no raw Atlassian credentials). |
| Failures | Problem response per controller; no success audit when publish does not complete. |

## Expected external artifact

- **Confluence:** new or updated page under the configured space; title/body reflect the published Markdown and include run/deep-link context generated by the report builder.
- **Response:** operator receives `externalPageId` (store/locate page in Confluence UI with vendor tools).

## Rollback and cleanup

- **Confluence:** archive or delete the pilot page; restrict space permissions for future smoke.
- **ArchLucid:** audit rows remain append-only; do not delete durable audit for production-like tenants.

## Troubleshooting

- **401/403:** token scopes, user access to space, or IP allow lists on Atlassian Cloud.
- **Wrong space:** fix `DefaultSpaceKey` / tenant publishing options — avoid publishing to production knowledge bases during smoke.
- **404 on run:** confirm `runId` exists in scope and the publish API uses the same id format as run detail UI.
