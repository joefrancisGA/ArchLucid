# SecureNow accessibility scope

## Where the public ArchLucid statement lives

The marketing page `/accessibility` is for the architecture-review host. On the security product line that route redirects to `/`. Do not treat that redirect as a SecureNow accessibility statement.

## How to report a barrier

Report a barrier to [`accessibility@archlucid.net`](mailto:accessibility@archlucid.net). This alias uses the same custodian path as the platform mailbox note; SecureNow does not invent a second mailbox.

## What this note does not do

This note does not claim WCAG certification. It does not claim a completed VPAT. It does not claim that assistive-technology user testing was performed.
