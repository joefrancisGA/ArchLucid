## Who it is for

Azure cloud-security, infrastructure, and security-architecture teams.

## What SecureNow shows

SecureNow shows which permission and network combinations in your Azure subscriptions form a possible access path, where an engineer could intervene, and whether a later capture supports that the condition changed.

## Walkthrough

1. Confirm scope and freshness on SecureNow Home before you trust a path ranking.
2. Open one ranked path in Priorities & waves and read cited hops in Path inspect.
3. Review an advisory cut point and any linked fix playbook.
4. The engineer changes Azure outside SecureNow under your organization's approvals.
5. Run a later capture and accept not verified when evidence or analysis is missing.
6. A person records the audit link to the relevant control.
