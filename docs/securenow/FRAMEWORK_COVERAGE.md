# SecureNow framework coverage

`frameworkMappings` cite a theme. They do not pass or fail a statute.

| Pack | What the mapping cites | Honest limit |
| --- | --- | --- |
| Microsoft cloud security benchmark | Microsoft cloud security benchmark themes in the platform policy-pack corpus. | Thematic architecture evidence, not a Microsoft certification or complete benchmark attestation. |
| NIST SP 800-53 | NIST SP 800-53 R5 control themes where a curated rule supplies a mapping. | A cited control theme is not a complete NIST assessment or authorization. |
| OWASP API Security Top 10 | OWASP API Security Top 10 categories in the application-security pack. | Category mapping is not an application-security certification or a pass/fail legal conclusion. |
| `arc-ampe-architecture-themes` | ARC-AMPE themes and related NIST SP 800-53 R5 references in the architecture pack. | Architecture themes are not CMS conformity, SSPP authoring, legal classification, or a CMS attestation. |
| `organization-security-architecture-starter` | Organization-authored framework themes supplied by the customer’s architecture team. | Placeholders are the architect’s text and are not a certification. |

## Editions

The generic edition leads with NIST SP 800-53, OWASP ASVS, and the Microsoft cloud security benchmark. The UHG edition leads with ARC-AMPE, then shows the generic list; neither edition turns a mapping into a certification.

## Reading boundary

The active pack and its source evidence determine what can be reviewed. SecureNow does not claim that this card enumerates every control in a framework, that a mapped rule is legally classified, or that the environment passed an audit.
