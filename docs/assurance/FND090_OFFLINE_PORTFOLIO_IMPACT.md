# FND-090 offline portfolio impact verification

The application evaluator accepts an already authorized FND-088 graph, an independently pinned observation capture and reviewed effects for the exact selected action IDs. A caller can capture a feasible FND-089 advisory selection and its optimizer-input hash. The simulation verifies graph feasibility but does not treat the optimizer's coverage points or graph coverage clauses as proof of impact. The same typed graph pin is required on the authorization, capture, and effect plan and includes scope, inventory digest, policy, engine and risk model versions. An observation-model version and referenced evidence digests are captured separately. SHA-256 identifies exact reviewed content, not the identity of the reviewer or correctness of the underlying evidence.

## Supported model

- Read-only, finite observations over already reviewed, opaque defensive control states. A named scenario can have several alternative observations. Each observation consists of a bounded conjunction of known-state conditions plus a reviewed evidence digest. The model can include a reviewed observation that is inactive at baseline to check for a modeled side effect.
- Each selected action needs a separately reviewed declarative effect and known expected starting state. Effects change only declared states in a private copy. Missing effects, undeclared controls and multiple writers are unsupported. A changed expected value is stale, and an unknown value cannot satisfy a precondition. Effects cannot run commands, resolve assets, call providers, create waves or write evidence.
- This is not a graph discovery or live analysis adapter. It evaluates only the declared observation roster, including declared side effects. Finding an observation absent does not establish that every possible route is absent. A production capture adapter or wider model would need its own evidence review. The evaluator is not registered in any production host.

## Comparison and status

The implementation reuses the existing scoped graph, digest utility and advisory selection contract. It follows the FND-014 private-copy and expected-state pattern without invoking a second runtime or the legacy simulation service. It follows FND-086's independent full-vs-incremental check without importing its separate synthetic harness or changing engine carry-forward. The incremental calculation re-evaluates every declared observation referencing a changed control, including ones that previously evaluated absent or unknown. An independent evaluator computes both full observations from scratch before the result is published. A mismatch, stop, or unsupported/stale effect returns no proposed-state or exposure claims.

At scenario level, one present observation is enough for a positive conclusion. Absence requires a complete capture and scenario roster, at least one observation, and all observations disproved. Otherwise the scenario stays unknown. A specific observation may disappear while its scenario remains or is unknown, and a regression may appear within a scenario that already existed. The result records both levels with evidence hashes and replayable before/after and plan digests. It reports modeled removal, remaining exposure, modeled introduction, scoped absence, and uncertainty separately, never a calibrated exposure percentage or verified customer outcome.

Focused tests cover alternate observations, complementary changes, introduced observations, stale and out-of-scope pins, incomplete evidence, immutable baseline, bounded or interrupted work, and a deliberately corrupted full-vs-incremental comparison. They also run a real FND-089 optimizer selection through the advisory adapter to verify that predicted coverage is not mistaken for a simulated result. The finite model and focused synthetic tests do not validate live engine fidelity. Pareto choices, richer sensitivity explanations, observed effectiveness and broader rollout assurance remain FND-091 through FND-093.
