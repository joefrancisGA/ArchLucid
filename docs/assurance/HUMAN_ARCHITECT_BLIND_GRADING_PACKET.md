# Human architect blind-grading packet

This packet is for the owner-executed blind panel. It contains **no ArchLucid answer key**.

## Panel

Use 2–3 experienced architects for the first directional study, then increase the panel/case count before stronger claims. Reviewers should not be told which output came from ArchLucid, another model, or a human.

## Materials per case

Provide the same evidence package to every evaluated system and reviewer:

- architecture brief and requirements;
- constraints and assumptions explicitly supplied to the participant;
- diagrams/declarations/evidence included in the case;
- time limit, if any;
- output format instructions.

Do not reveal planted defects, expected findings, hidden rubric notes, prior versions, or system identity.

## Reviewer task

For each anonymized output, independently grade:

- important issue recall;
- false positives;
- severity calibration;
- evidence sufficiency;
- recognition of conflicting objectives and tradeoffs;
- recommendation usefulness/feasibility;
- unsupported assertions;
- internal contradictions;
- consistency with supplied artifacts;
- time-to-result if the experiment measures assisted workflow.

Use 0–4 ordinal grades per dimension plus free-text notes. Record **misses separately** rather than hiding them inside an average.

## Hard-gate questions

Answer yes/no:

- Did the output invent evidence?
- Did it invent or misstate a regulation?
- Did it state certainty unsupported by the supplied evidence?
- Did it contradict another artifact/output section?
- Did it present missing evaluation as a clean result?

Any yes must remain visible regardless of average scores.

## Blinding procedure

1. Assign random output labels unrelated to source.
2. Separate the person preparing labels from graders where practical.
3. Freeze outputs before grading.
4. Collect grades independently before discussion.
5. Resolve rubric ambiguity only after individual grades are locked.
6. Preserve raw grades and disagreements.

## Interpretation

The first panel is directional evidence, not statistical proof of superiority. “Elite-human-level” requires repeated held-out results against genuinely qualified external humans and must retain population, sample size, task scope and uncertainty.
