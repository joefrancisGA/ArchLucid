# Accelerator packs (V1)

**Audience:** Sales engineers, pilot operators, and sponsors evaluating a **vertical or posture-specific** first review without V1.1 connectors.

**Spine:** Every accelerator follows the same shipped sequence — **capture → evidence → policy packs → findings → commit → sponsor export**. Start from [`FIRST_PILOT_OPERATOR_PATH.md`](../../runbooks/FIRST_PILOT_OPERATOR_PATH.md) when the tenant is not yet configured; use a row below when you need a **named buyer narrative**.
