# Customer glossary

The in-app glossary at [`/help/glossary`](/help/glossary) is the canonical customer-facing terminology reference.

## Core nouns

| Term | Meaning |
| --- | --- |
| **Architecture review** | The governed evaluation workflow from intake through finalize |
| **Architecture package** | Durable outputs for one review — findings, decisions, evidence links, signed review record, and exports (prefer over legacy *review package*) |
| **Finalize** | Lock the signed review record and package for governance and export |
| **Evidence graph** | Visual trail from findings back to source evidence |
| **Architect** | Day-to-day review role (identity claim may still say `Operator`) |

Use [`/help/glossary`](/help/glossary) for the full definition set, including governance and organization terms.

Engineering field taxonomies and record schemas are documented separately for contributors only.
