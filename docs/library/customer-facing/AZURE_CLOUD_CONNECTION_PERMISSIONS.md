# Azure permissions for cloud connections

Grant ArchLucid the minimum read-only Azure roles required for hosted cloud connections.

The in-app guide at `/help/azure-permissions` is the canonical, manifest-driven reference for:

- required and conditional Azure roles;
- supported assignment scopes;
- setup, verification, and custom-role actions;
- what ArchLucid collects and cannot change.

Use that page when assigning roles to the ArchLucid enterprise application in your tenant.
