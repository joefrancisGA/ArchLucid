# Users and roles

The in-app guide at [`/help/users-and-roles`](/help/users-and-roles) is the canonical customer-facing reference for workspace roles and access management.

## Built-in roles (buyer labels)

| Label | Typical user | Notes |
| --- | --- | --- |
| **Admin** | Workspace administrator | Users, billing, governance activation, integrations |
| **Architect** | Day-to-day review work | Create and finalize architecture packages; claim/API value remains `Operator` |
| **Reader** | Stakeholder reviewer | View reviews and findings without changing evidence |
| **Auditor** | Compliance reviewer | Read-focused with audit export |

Use the in-app page for the capability matrix, invite steps, and common questions.

Engineering authentication configuration is documented separately for contributors only.
