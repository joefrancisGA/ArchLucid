## Legend

| Status label | Meaning |
|--------------|---------|
| **Shipped** | Product code paths exist; **automated** tests run in CI (mocks or API fixture). |
| **Shipped + manual vendor** | Same as **Shipped**, plus operator **live** validation against the vendor (see smoke doc). |
| **Recipe** | **Customer-operated** pattern under [`../integrations/recipes/README.md`](../integrations/recipes/README.md) or [`../../templates/integrations/README.md`](../../templates/integrations/README.md) — **not** a substitute for first-party commitments where scope applies. |
| **Planned** | Roadmap / deferred — **do not** treat as available product surface until promoted in [`V1_SCOPE.md`](V1_SCOPE.md) or an owner decision. |

**Surface:** **Product** = first-party hosted API, worker, or package; **Recipe** = optional customer automation.
