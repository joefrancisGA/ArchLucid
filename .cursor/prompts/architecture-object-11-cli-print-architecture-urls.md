# AO-11 — CLI prints architecture locator URLs for Working-shaped output

**Do not fork CA-43** list/get. Extend printed URLs.

## Goal

`archlucid` commands that print a UI URL for a review/draft print the nested Working locator when ArchitectureId is present. `--json` includes `architectureUrl` + `reviewUrl` (nested).

## Why

Operators live in terminals. CLI that prints `/architecture/reviews/{guid}` retrains the peer product.
