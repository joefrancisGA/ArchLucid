# WA-03 — Engineer chrome is not Working density

**Do not fork LD-01 or LD-10** for the resolver or golden-path Redis/Service Bus banners. This file is the leftover **classification**: COGS, Fleet LLM budget, RAG health, packager, extractor ZIP, and similar engineer widgets must not appear because the user is in Working mode.

## Goal

Engineer widgets render only when `isOperatorExperienceFullShellEnv()` **and** the principal can act (admin/capability). Working production (env-unset) stays architect nouns: Review → Evidence → Decision. Guided/demo never grow these pills. `NEXT_PUBLIC_OPERATOR_EXPERIENCE=operator` remains internal engineer chrome.

## Why

Density is not a license to teach how ArchLucid is built. LD-10 demoted vendor strings from Home/intake titles. Remaining mounts still key off “full shell or Working chrome.” A professional architect’s desk is not a vendor ops console. Casual products put the platform’s COGS in the header to look “real.”
